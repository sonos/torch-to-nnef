👀 Live Demo: Voice Activity Detection

This demo runs a Voice Activity Detection (VAD) model based on NVIDIA MarbleNet. VAD estimates the probability that speech is present in short audio frames. MarbleNet is a lightweight convolutional architecture designed for accurate, low‑latency speech/no‑speech detection.

Modes: Pulsed streams the encoder with small (4‑frame) updates for low latency; Batch computes the encoder on a larger context window each step for reference parity; Both plots the two scores side‑by‑side so you can compare behavior.
